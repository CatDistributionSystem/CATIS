# CDS-OPS-001

## 对处于困境中的猫作出响应

**文件编号：** CDS-OPS-001  
**版本：** Beginning 1e01  
**状态：** 已批准  
**主语言：** 英语  
**文件系列：** 操作程序  
**主管机构：** Cat Distribution System (CDS)

---

### 1. 目的

本程序确立系统在观察到或接获报告称猫处于困境时作出响应所遵循的原则和行政步骤。

本程序旨在确保此类情况得到适当关注，相关情况得到记录，并且适当的援助不会因行政要求而延误。

### 2. 基本原则

**猫处于困境这一事实本身，就足以构成系统采取行动的理由。**

启动响应不以存在分配个案、登记记录、已确认的主人、候选人或此前与系统有过接触为前提。

猫所处的实际情况优先于其行政记录的完整性。

### 3. 适用范围

本程序适用于包括但不限于以下情况：

- 猫出现明显的身体不适或受伤。
- 猫处于不安全或不适宜的环境中。
- 猫无法获得必要的食物、饮水或庇护。
- 猫走失、被遗弃或明显遭到疏于照料。
- 猫所处的情况表明其需要立即获得援助。
- 任何其他可能危及猫福祉的情况。

无论该猫此前是否为系统所知，本程序均适用。

### 4. 响应程序

#### 4.1 识别

系统可通过直接观察、个人提供的信息、现有个案记录或其他可观察到的表现获知困境情况。

信息不完整或未经独立核实，本身并不足以成为忽略报告的理由。

#### 4.2 初步评估

应审查现有信息，以确定：

- 猫的表面状况。
- 发现该情况时的具体环境。
- 是否可能需要立即援助。
- 是否已有适当援助可供提供。
- 是否需要进一步信息。

评估应以现有证据为依据，不得将推测表述为已确认的事实。

#### 4.3 立即援助

当猫看起来需要紧急的身体救助时，必须在不等待行政处理的情况下寻求适当的现实救助。

根据具体情况，援助可来自兽医专业人员、动物救援服务、地方主管机关，或能够提供适当即时援助的个人。

CDS 行政程序不取代专业兽医评估或紧急干预。

**行政记录的完整性绝不得优先于猫的即时福祉。**

#### 4.4 协调

在适当情况下，系统可协调现有信息，并协调相关个人或服务机构的参与。

响应应考虑猫所处的情况以及现有援助是否适当。

不得仅凭初步评估就预先认定任何特定结果。

#### 4.5 后续跟进

如仍有相关信息，应记录后续发展。

内容可包括：

- 猫所处情况的变化。
- 已提供或已安排的援助。
- 进一步观察结果。
- 对猫当前状况的确认。
- 被认为有必要采取的任何其他行动。

### 5. 文档记录

可按照适用的 CATIS 文档规范建立该情况的记录。

如有相关信息，记录应区分：

- 直接观察所得。
- 第三方报告的信息。
- 评估及行政结论。
- 已采取的行动。
- 后续发展。

不得以推测填补缺失的信息。

记录困境情况不要求事先存在分配记录。

### 6. 个案状态与结案

如现有信息表明即时情况已得到处理，或目前无需采取进一步行政行动，则可将该困境情况视为行政结案。

行政结案并不保证猫今后持续处于良好状态。

如情况发生变化或出现新信息，可再次对该情况予以关注。

### 7. 行政限制

本程序不制定兽医诊断标准，不规定医疗治疗，也不取代合格专业人员及相关主管机关的职责。

本程序规范系统对困境情况的行政关注、协调及记录工作。

### 8. 最终条款

缺少完整记录并不否定已经观察到的情况。

没有已确认的分配个案，并不妨碍系统作出响应。

**在整个程序过程中，猫的福祉始终是首要考虑。**
