# CDS-REG-002 — Реестр документации ограниченного доступа

**Статус документа:** Утверждён  
**Редакция:** 7e65.4  
**Язык:** Русский

## Назначение

Настоящий реестр содержит сведения о документации, названия, отдельные сведения или содержание которой недоступны для публичного ознакомления.

Наличие записи не означает, что соответствующие материалы размещены в открытой части репозитория. Публичная запись может указывать на документ, сохраняя его название или содержание закрытыми.

## Реестр

| Идентификатор документа | Название | Статус раскрытия |
|---|---|---|
| CATIS-REF-001 | CATIS System Reference and Chronology | Сведения не раскрываются |
| CATIS-REF-002 | Название не раскрывается | Сведения не раскрываются |
| CATIS-REF-003 | Seventh Epoch Reset and Continuity | Сведения не раскрываются |
| CDS-OPS-005 | Название не раскрывается | Сведения не раскрываются |
| CDS-OPS-006 | Название не раскрывается | Сведения не раскрываются |

## Публикация и доступ

Если документ ограниченного доступа представлен файлом в публичном репозитории, файл содержит только следующую надпись:

> Available to System administrators only

В портале CATIS для записи ограниченного доступа используется утверждённое название, если его раскрытие разрешено. Ссылка на открытую редакцию заменяется соответствующей отметкой о нераскрытии сведений.

Реестр может обновляться независимо от публикации содержания документов.
