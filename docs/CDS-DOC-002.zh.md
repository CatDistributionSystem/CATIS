# CDS-DOC-002

## 术语与定义

**文件编号：** CDS-DOC-002  
**版本：** 0.1  
**状态：** 已批准  
**主语言：** 英语  
**本版本语言：** 中文  
**主题：** 猫咪分配系统（CDS）及 CATIS 文档中使用的术语

---

## 1. 目的

本文件为涉及猫咪分配系统（CDS）及其技术平台 CATIS 的文档建立统一的术语框架。

其目的是确保所有官方语言版本及相关出版物中的名称、概念和定义保持一致。

本文件仅定义术语，不确立新的操作程序、技术能力或系统内部机制。

## 2. 核心术语

### 2.1. Cat Distribution System（CDS，猫咪分配系统）

一个独立的系统，用于确定猫咪出现在人们生活中的规律，并在考虑个人情况和适宜条件的基础上协调猫咪分配流程。

CDS 是该系统的国际标识。

### 2.2. 系统

对 Cat Distribution System（CDS）的简称。

该术语指 CDS 本身，不得使人误以为 CDS 是通常意义上的机构、部门、代理机构或行政中心。

### 2.3. CATIS

**Cat Allocation & Tracking Information System（CATIS）** 是为 Cat Distribution System 的各项流程提供支持的技术平台。

CDS 与 CATIS 是彼此独立的实体。CATIS 不是 CDS 的替代名称。

### 2.4. 系统管理员

由系统指定的管理员。

系统管理员可以了解 CATIS 的用途、能力及运行原则。本文件不规定其组织架构、个人职责、权限或访问程序。

### 2.5. 猫咪分配

在考虑个人情况和适宜条件的基础上，协调猫咪出现在某人生活中的过程。

该术语描述系统活动的一般领域，并不确立任何特定的分配程序。

### 2.6. 候选人

可能通过与系统相关的流程成为猫咪接收者的人。

使用这一术语并不意味着必然存在正式的申请、登记或遴选程序。

## 3. 文档术语

### 3.1. 主语言

作为国际文档权威参照的语言。

英语是 CDS 和 CATIS 文档的主语言。

### 3.2. 官方语言版本

以某一特定语言编写的官方文件版本。

CDS 文档的六种官方语言为英语、法语、西班牙语、俄语、中文和阿拉伯语。

### 3.3. 平行版本

与主语言文件具有相同文件编号和版本号的官方语言版本。

平行版本应保留主文件的含义、范围和状态。

### 3.4. 已确认特征

已在相关批准文件中正式确立的能力、特征或要求。

某项内容仅仅出现在提案或初步文件中，并不构成对该内容的确认。

### 3.5. 提案

尚未正式批准的建议性概念、能力、要求或变更。

不得将提案描述为 CDS 或 CATIS 已确立的特征。

## 4. 术语区分

在所有 CDS 和 CATIS 文档中，必须保持以下区分：

1. **CDS 与 CATIS：** 系统及其配套技术平台是彼此独立的实体。
2. **系统与组织：** 不得将 CDS 描述为通常意义上的机构、部门、代理机构、组织或中心。
3. **猫咪分配与具体程序：** 分配这一一般概念并不确立任何具体的操作程序。
4. **已确认特征与提案：** 不得将提议中的能力描述为已经实施或批准。
5. **可观察结果与内部机制：** 对可观察事件和结果的描述，不得用于披露或推断 CDS 未公开的内部机制。

## 5. 语言与翻译规则

1. 英语是国际文档的权威参照语言。
2. 法语、西班牙语、俄语、中文和阿拉伯语官方版本作为平行版本维护。
3. CDS 标识必须在所有语言版本中保持一致。
4. CATIS 名称及其完整英文名称必须保持不变。
5. 翻译必须保留 CDS 与 CATIS 之间的概念区别。
6. 如果某个术语在目标语言中没有直接对应词，翻译应保留其既定含义，而不得引入新概念。

## 6. 范围与限制

本文件建立统一的术语框架，但并不构成涵盖未来 CDS 或 CATIS 文档中所有术语的完整词汇表。

后续经批准的文件可以引入其他术语。

任何新定义都必须符合 CDS 已确立的性质、CDS 与 CATIS 之间的区别，以及相关批准文件所规定的文档原则。
