# CDS-OPS-003

## 紧急情况升级处置程序

**文件编号：** CDS-OPS-003  
**版本：** Beginning 1e01  
**状态：** 已批准  
**主语言：** 英语  
**文件系列：** 操作程序  
**主管机构：** Cat Distribution System (CDS)

---

### 1. 目的

本程序确立适用于涉及处于困境中的猫或人的紧急情况升级处置原则和行动措施，尤其是在可能需要立即干预时。

本程序为 CDS-OPS-001《对处于困境中的猫作出响应》和 CDS-OPS-002《对处于困境中的人作出响应》提供共同的升级处置框架。

本程序旨在确保紧急情况得到适当关注，并及时寻求现实世界中的援助。

### 2. 基本原则

**紧急情况优先于所有行政程序。**

当猫或人看起来正面临对生命、健康或安全的直接或可能迫在眉睫的威胁时，必须在不等待行政处理、评估完成或系统授权的情况下，寻求适当的现实世界紧急援助。

不得将任何行政要求解释为推迟紧急干预的理由。

### 3. 适用范围

本程序适用于涉及以下情形的紧急情况：

- 猫遭受可能危及生命的伤害或病况。
- 猫面临直接危险，或处于存在严重风险的环境中。
- 人遭遇医疗紧急情况，或其人身安全受到直接威胁。
- 某人的处境表明其可能即将遭受严重伤害。
- 任何其他延误可能显著恶化猫或人的处境与结果的情况。

无论受影响的人或猫此前是否为系统所知，本程序均适用。

### 4. 紧急情况升级处置程序

#### 4.1 识别

可通过直接观察、个人提供的信息、现有个案记录或其他可用来源识别紧急情况。

如果具体情况合理表明存在直接风险，则启动紧急援助不以信息完整或经过独立核实为前提。

#### 4.2 立即行动

一旦识别出紧急情况，必须立即联系适当的现实世界紧急援助服务。

根据具体情况，可包括：

- 紧急医疗服务。
- 兽医急救服务。
- 消防与救援服务。
- 警方或其他相关公共主管机关。
- 动物救援或动物福利组织。
- 其他具备资质的紧急响应人员。

援助服务的选择应与紧急情况的性质以及受影响猫或人的所在地相适应。

如无法确定应联系哪项服务，应联系当地可用的紧急服务寻求指导。

#### 4.3 升级处置路径

以下步骤构成一般升级处置路径：

1. **识别紧急情况。** 识别猫或人所面临的明显直接风险。
2. **启动现实世界援助。** 立即联系适当的紧急服务或具备资质的响应人员。
3. **提供现有信息。** 说明已知情况、地点和紧急情况的性质。
4. **遵循专业人员指示。** 配合紧急响应人员并遵循其指导。
5. **确保援助连续性。** 在可能的情况下，确保相关人员知悉情况，并确保援助持续可用，直至即时情况得到处理。
6. **记录结果。** 在记录工作不再妨碍紧急响应时，记录已采取的行动及任何后续信息。

如果首次联系的服务无法提供援助，必须寻求其他适当服务。首次联系未能成功，不构成终止升级处置的理由。

#### 4.4 协调

在适当情况下，可通知相关个人和服务机构有关紧急情况及正在安排的援助。

协调工作不得干扰具备资质的响应人员开展工作，也不得造成额外延误。

受影响猫或人的即时需求始终是首要考虑。

#### 4.5 信息缺失或不完整

缺少信息、情况存在不确定性，或无法确定紧急情况的完整性质，均不得妨碍寻求适当援助。

应准确传达现有信息。不得将未知细节表述为已确认事实。

### 5. 文档记录

与立即干预相比，紧急情况的文档记录处于次要地位。

在具体情况允许时，可记录以下信息：

- 受影响猫或人的身份信息（如有）。
- 紧急情况发生的地点及具体情况。
- 按照适用文档规范记录的识别时间。
- 已联系的紧急服务或响应人员。
- 已采取的行动及收到的指示。
- 后续发展及已知结果。

即时紧急情况得到处理后，可补充或完善相关记录。

### 6. 后续跟进与结案

初步干预之后，应审查现有信息，以确定是否需要进一步援助、协调或行政行动。

如现有信息表明即时紧急情况已得到处理，且目前无需采取进一步升级措施，则可将该紧急情况视为行政结案。

行政结案并不代表已确认完全康复，也不保证今后不再需要援助。

如新信息表明紧急情况再次发生或仍在持续，必须重新启动升级处置程序。

### 7. 行政限制

本程序不制定医学或兽医学诊断标准，不规定治疗，不取代紧急服务，也不向 CDS 管理员赋予专业职责。

所有现实世界中的紧急干预仍由适当的合格专业人员及相关主管机关负责。

CDS 的行政协调仅起辅助作用，绝不得妨碍、延误或取代此类干预。

### 8. 最终条款

缺少完整记录并不妨碍启动紧急情况升级处置。

没有已确认的分配个案，并不妨碍启动紧急情况升级处置。

缺少确认信息，并不能成为忽略明显紧急情况的理由。

**需要立即援助时，行动优先于行政程序。**
